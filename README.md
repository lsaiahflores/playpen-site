# playpen.site

The public website for Playpen. Plain static HTML, CSS and a little vanilla JS. No framework, no trackers, no third-party scripts,
no CDN (the two fonts are bundled, both SIL Open Font License).

- `index.html`, `download/`, `parents/`, `faq/`, `404.html`: generated by `node tools/build.js`.
- `terms/` and `privacy/`: drafts, marked noindex and not linked until approved.
- `play/maze/`: the page the QR code opens: a full-screen frame onto the game at play.playpen.site. See `play/README.md`.
- `supabase/`: the SQL and notes for the beta signup list. See `supabase/README.md`.
- `js/config.js`: the Supabase URL and anon key (empty until the project exists).
- `tools/`: build and test scripts. `cd tools && npm install && node test-site.js`.

All URLs inside the pages are relative, so the same files work on GitHub Pages, on a custom domain, or on Cloudflare Pages
(build command: none; output directory: `/`).

This repository contains only the website. It holds no Playpen source code and no secrets.
